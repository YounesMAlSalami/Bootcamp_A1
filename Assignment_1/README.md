
# Password Strength Checker

أداة سطر أوامر (CLI) خفيفة بلغة C لتقييم وفحص مدى قوة وتعقيد كلمات المرور بناءً على معايير الأمان الأساسية.

## 📋 ما تم انجازه في هذا التكليف:
* التحقق من طول كلمة المرور (ألا يقل عن 8 أحرف).
* فحص نوعية الأحرف المستخدمة داخل كلمة المرور للتأكد من تنوعها.
* تصنيف كلمة المرور وإعطاء تقرير تفصيلي (ضعيفة، متوسطة، قوية).

## ⚙️ كيف تعمل الأداة؟
1. يطلب البرنامج من المستخدم إدخال كلمة المرور.
2. يتم فحص النص حرفاً بحرف باستخدام دوال مكتبة `<ctype.h>` للتحقق من وجود:
   * حروف كبيرة (Uppercase)
   * حروف صغيرة (Lowercase)
   * أرقام (Digits)
   * رموز خاصة (Symbols)
3. طباعة تقرير يوضح الشروط المتوفرة والمفقودة والنتيجة النهائية.

## 🛠️ متطلبات التشغيل:
* أي مُترجم لغة C (مثل `gcc`).

## 🚀 كيفية التشغيل:

1. **ترجمة الكود (Compilation):**
   افتح الـ Terminal أو موجه الأوامر في مجلد المشروع، ثم اكتب الأمر التالي:
   ```bash
   gcc password_checker.c -o password_checker
2. تشغيل البرنامج:
   على Linux / macOS / PowerShell:
   ```bash
   ./password_checker



على Command Prompt (CMD) في Windows:

```bash
   password_checker.exe
