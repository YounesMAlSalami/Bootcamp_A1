
# Hexadecimal Viewer (عراض الملفات الثنائية)

أداة سطر أوامر (CLI) بلغة C مصممة لقراءة الملفات الثنائية وعرض بياناتها الخام بشكل جدول منسق يجمع بين النظام الست عشري (Hex) وتمثيل الـ ASCII.

## 📋 ما تم انجازه في هذا التكليف:
* استقبال اسم الملف المراد فحصه مباشرة كمعامل عبر سطر الأوامر (`argv`).
* فتح الملف في وضعية القراءة الثنائية الآمنة (`rb`).
* قراءة الملف على دفعات بكتل منتظمة (16 بايت في كل دورة).
* طباعة موقع البايت (Offset) وقيم الـ Hex بجانب تمثيل الـ ASCII المقابل لها.

## ⚙️ كيف تعمل الأداة؟
1. يمرر المستخدم اسم الملف مع أمر التشغيل.
2. تقرأ الأداة محتوى الملف بايت ببايد وتخزنه في مصفوفة مؤقتة (Buffer).
3. تُطبع القيم بصيغة `Hex` مع استبدال الرموز غير القابلة للطباعة بنقاط (`.`) في قسم الـ ASCII لسهولة التحليل والقراءة.
4. إغلاق الملف بأمان (`fclose`) عند الانتهاء.

## 🛠️ متطلبات التشغيل:
* أي مُترجم لغة C (مثل `gcc`).

## 🚀 كيفية التشغيل:

1. **ترجمة الكود (Compilation):**
   افتح موجه الأوامر في مجلد المشروع، ثم اكتب الأمر التالي:
   ```bash
   gcc hex_viewer.c -o hex_viewer

 2. **تشغيل البرنامج وفحص أي ملف:**
   * على **Linux / macOS / PowerShell**:
     ```bash
     ./hex_viewer filename.txt
     
   * على **Command Prompt (CMD) في Windows**:
     ```cmd
     hex_viewer.exe filename.txt
