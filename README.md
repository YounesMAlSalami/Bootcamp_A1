# Bootcamp A1 - Cybersecurity & Network Analysis Training

مستودع شخصي لتوثيق المهام، التكاليف، والمشاريع التطبيقية ضمن **مخيم التدريب المكثف للأمن السيبراني (22 أسبوعاً / 415 ساعة)** بتنظيم من **شركة A1 للاستشارات** و**مركز ألتمت للتدريب والاستشارات** في صنعاء.

---

## 🗺️ نبذة عن البرنامج التدريبي:
* **المرحلة الأولى (التأسيسية - أونلاين):** التركيز على لغات البرمجة الأساسية (C Programming, Python, JavaScript & PHP).
* **المرحلة الثانية (التخصصية - حضوري):** تغطي مسارات متقدمة تشمل الأمن السيبراني الأساسي، اختبار الاختراق، تحليل السجلات والتهديدات، والهندسة العكسية للبرمجيات الخبيثة.
* **المشاريع النهائية:** تطبيق عملي ومشاريع تقييمية بإشراف خبراء المجال.

- **الأمن السيبراني:**
  - Password Strength Checker
  - Hexadecimal Viewer
  - TCP Port Scanning
  - Banner Grabbing
  - Log Analysis
  - File Integrity Monitoring (FIM)
  - SQL Injection Defense
  - Secure File Upload
  - Session & Cookie Security
  - DOM-Based XSS Prevention
- **بيئة العمل:** Windows, Terminal, PowerShell, GCC, Python, PHP (XAMPP).
- **إدارة المشاريع:** Git & GitHub.
