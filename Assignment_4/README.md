
# SOC Log File Parser (أداة تحليل السجلات)

أداة سطر أوامر (CLI) بلغة C مخصصة لمحللي أمن المعلومات، تقوم بقراءة ملفات السجلات والبحث داخلها عن كلمات مفتاحية مشبوهة أو محددة لاستخراج السطور المخالفة وإعطاء تقرير إجمالي.

## 📋 ما تم انجازه في هذا التكليف:
* فتح ملفات السجلات وقراءتها بفعالية سطرًا بسطر باستخدام `fgets` لضمان عدم استهلاك الذاكرة.
* البحث عن الكلمات المفتاحية المطلوبة بطريقة غير حساسة لحالة الأحرف (Case-Insensitive).
* طباعة أرقام السطور والمحتوى المخالف عند اكتشاف التطابق.
* عرض ملخص إجمالي بعدد السجلات المشبوهة المكتشفة عند نهاية الفحص.

## ⚙️ كيف تعمل الأداة؟
1. يستقبل البرنامج اسم ملف السجل والكلمة المراد البحث عنها عبر سطر الأوامر (`argv`).
2. يفتح الملف في وضع القراءة النصية (`r`).
3. يمر البرنامج على السطور سطرًا بسطر، ويقوم بمقارنة محتواها بكلمة البحث.
4. إذا وجد تطابقاً، يقوم بطباعة رقم السطر ومحتواه مع زيادة عداد التنبيهات، ثم يغلق الملف بأمان في النهاية.

## 🛠️ متطلبات التشغيل:
* أي مُترجم لغة C (مثل `gcc`).

## 🚀 كيفية التشغيل:

1. **ترجمة الكود (Compilation):**
   افتح موجه الأوامر في مجلد المشروع، ثم اكتب الأمر التالي:
   ```bash
   gcc log_parser.c -o log_parser

 2. **تشغيل البرنامج (مثال للبحث عن كلمة failed):**
   * على **Linux / macOS / PowerShell**:
     ```bash
     ./log_parser server.log failed
     
   * على **Command Prompt (CMD) في ويندوز**:
     ```cmd
     log_parser.exe server.log failed
