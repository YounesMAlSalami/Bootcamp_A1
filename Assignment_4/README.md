# SOC Log File Parser (أداة تحليل السجلات)

أداة سطر أوامر (CLI) بلغة C مخصصة لمحللي أمن المعلومات، تقوم بقراءة ملفات السجلات والبحث داخلها عن كلمات مفتاحية مشبوهة أو محددة، واستخراج السطور المطابقة وعرض تقرير إجمالي بنتائج الفحص.

## 📋 ما تم إنجازه في هذا التكليف

- فتح ملفات السجلات وقراءتها بفعالية سطراً بسطر باستخدام `fgets` لتجنب استهلاك الذاكرة بالكامل.
- البحث عن الكلمات المفتاحية المطلوبة بطريقة غير حساسة لحالة الأحرف (Case-Insensitive).
- طباعة أرقام السطور والمحتوى المطابق عند اكتشاف التطابق.
- عرض ملخص إجمالي بعدد السجلات المشبوهة المكتشفة عند انتهاء الفحص.

## ⚙️ كيف تعمل الأداة؟

1. يستقبل البرنامج اسم ملف السجل والكلمة المراد البحث عنها عبر معاملات سطر الأوامر (`argv`).
2. يفتح الملف في وضع القراءة النصية (`r`).
3. يمر البرنامج على محتويات الملف سطراً بسطر، ويقارن كل سطر بكلمة البحث.
4. عند العثور على تطابق، يطبع رقم السطر ومحتواه، ويزيد عداد التنبيهات.
5. يغلق الملف بأمان بعد انتهاء عملية الفحص.

## 🛠️ متطلبات التشغيل

- مترجم لغة C مثل `GCC`.
- ملف سجل نصي لاستخدامه كمدخل للأداة.

## 🚀 كيفية التشغيل

### 1. ترجمة الكود (Compilation)

افتح موجه الأوامر داخل مجلد المشروع، ثم نفّذ:

```bash
gcc log_parser_soc.c -o log_parser_soc
```

### 2. تشغيل البرنامج

مثال للبحث عن الكلمة `failed` داخل ملف `server.log`.

**على Linux / macOS / PowerShell:**

```bash
./log_parser_soc server.log failed
```

**على Windows Command Prompt (CMD):**

```cmd
log_parser_soc.exe server.log failed
```

## 🧰 التقنيات المستخدمة

- **لغة البرمجة:** C
- **معالجة الملفات:** File Handling باستخدام `fopen` و`fgets` و`fclose`.
- **معالجة النصوص:** البحث عن الكلمات المفتاحية بطريقة غير حساسة لحالة الأحرف.
- **مدخلات سطر الأوامر:** Command-Line Arguments (`argc` و`argv`).
